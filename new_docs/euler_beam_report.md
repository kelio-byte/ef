# Euler-Beam: 并行 Euler 轨迹维护的逆合成采样方法

## 1. 动机：来自轨迹可视化的洞察

### 1.1 观测样本

在测试集第 1828 号产物上进行轨迹可视化分析时，发现了两个关键现象：

**产物**:
```
c 1 c ( C = O ) c c c ( N C ( C ( C ) ( C ) C ) = O ) n 1
```

**目标反应物**:
```
c 1 c ( Br . C ( N ( C ) C ) = O ) c c c ( N C ( C ( C ) ( C ) C ) = O ) n 1
```

核心编辑：醛基 `C=O` → 溴原子 `Br` + 酰胺片段 `C(N(C)C)=O`（一次替换 + 一次插入）。

### 1.2 发现一：同源异果

在多次独立 Euler 采样中观察到：即使在**早期步骤做出相同或高度相似的编辑**，后续由于每步的随机性（泊松触发 + multinomial 选 token），轨迹会逐步发散，最终走向**完全不同的结果**——有的命中 target，有的生成无效 SMILES。

```
Step 0-20:  编辑位置和 token 高度一致  ← "同步期"
Step 20-60: 开始分化，但编辑方向相近   ← "分化期"
Step 60-100: 彻底发散，通往不同结果      ← "发散期"
         ┌→ 轨迹 A → 命中 target ✓
x_0 ────┼→ 轨迹 B → 接近但略有偏差 ✗
         └→ 轨迹 C → 有效但非 target ✗
```

**启示**: 单条 Euler 轨迹的命运高度随机。模型在每一步给出了合理的 rate 和 prob 分布，但掷骰子的方差可能导致"本可命中"的轨迹因一次不幸的采样而失去机会。

### 1.3 发现二：殊途同归

相反地，也观察到：**不同的早期编辑路径**最终可能收敛到**相同或等价的反应物**。例如：

```
         路径 1: step 15 先 SUB C→Br, step 42 再 INS =N...
x_0 ────┤                                          ┌→ 均命中 target ✓
         路径 2: step 23 先 INS =N, step 51 再 SUB C→Br...
```

不同编辑顺序，最终产物一致。这在化学上是合理的——逆合成路径不唯一，但最终反应物是确定的。

**启示**: 多条路径汇聚到同一结果时，该结果的可信度应该更高。单条 Euler 无法利用这种"共识"信号。

### 1.4 核心洞察

| 现象 | 单条 Euler 的处理 | 想要的行为 |
|:---|:---|:---|
| 同一初始状态可走向不同结果 | 随机选一条，听天由命 | 多路并行探索，保留不同可能性 |
| 不同路径可汇聚到同一结果 | 无法感知 | 合并加权，共识度高→可信度高 |
| 某些分支死锁（100 步 0 编辑） | 浪费一次采样机会 | 尽早淘汰，释放预算给活跃分支 |

这自然导向了一个 **Beam Search + Euler 随机采样** 的混合方案。

## 2. 方法：Euler-Beam

### 2.1 核心思想

维护 **K 条并行 Euler 轨迹**（分支），每步：

1. **共享前向**: K 条父分支拼成 batch → **单次模型调用**，输出 log_rates + log_probs
2. **K×M 采样**: 每条父分支用自己的随机种子采样 **M 个独立后继（child）**，保留 Euler 0~N 编辑/步的灵活性 → 每步生成 **K×M 个候选**
3. **去重合并**: 产生相同 token 序列的候选合并概率质量（共识信号，logsumexp）
4. **Top-K 剪枝**: 按聚合概率质量（可选加 changed-state 先验）排序，保留 K 条高质量分支
5. **分裂补充 (M=1 兼容)**: 仅当 M=1 且不同结果不足 K 条时，从高排名分支克隆补足；M>1 时 K×M 真实候选已足够，不复制

### 2.2 与纯 Euler 和传统 Beam Search 的对比

| | Euler | 传统 Beam Search | **Euler-Beam** |
|:---|:---|:---|:---|
| 编辑选择 | 随机采样 | argmax (确定性) | **随机采样** |
| 每步编辑数 | 0~N 个 | 1 个 | **0~N 个** |
| 并行度 | 1 条/样本 | K 条 beam | **K 条分支** |
| 多样性来源 | 随机种子 | beam 分叉 | **随机种子 + 分支分化** |
| 共识利用 | 无 | 无 | **去重加权** |
| 输出 | N 条/样本 | 1 条/样本 | **N 条/样本（N 次独立 run）** |

Euler-Beam 继承了 Euler 的灵活编辑能力（每步可编辑任意多个位置）和传统 Beam 的剪枝效率，同时引入了**去重共识加权**这一独特机制。

### 2.3 分支状态

```python
class _BranchState:
    x_t: Tensor       # (1, L) 当前 token 序列
    weight: float     # 共识权重 — 多分支汇聚至此 = 高权重
    path_log_p: float # 编辑路径累计 log-prob — ≤0，越大越好（M=1 兼容排序用）
    log_mass: float   # 状态概率质量的 Monte Carlo 估计 — M>1 正式模式排序主键
    t: float          # 当前连续时间
    seed: int         # 随机种子 — 保证分支间独立性
```

### 2.4 排序策略

```python
# M>1 正式模式: 主键 = 聚合状态概率质量 (Monte Carlo log_mass, 相同状态 logsumexp 合并)
#               可选 + changed_state_bonus: 给偏离 product 的状态一个固定搜索先验
# M=1 兼容模式: (path_log_p, weight) — 完整单轨迹 log-prob
# legacy 消融:  (-path_log_p, weight) — 越激进越优先的启发式，非概率解释
```

正式模式在 **聚合概率质量** 层面排序：同一最终 token 状态的所有候选先合并（logsumexp 聚合 `log_mass`），再按合并后的质量保留 Top-K。因此"殊途同归"的共识信号直接转化为更高的存活优先级；编辑过的分支 `path_log_p < 0`，闲置分支 `path_log_p = 0`。

## 3. 实验验证

### 3.1 实验设置

| 配置项 | Euler-Beam | Euler |
|:---|:---|:---|
| 测试集 | USPTO_50K tiny (50 产物 × 20 augmentations) | 同左 |
| 模型 | checkpoint_step600000.pt | 同左 |
| 采样步数 | n_steps=100 | 同左 |
| 分支数/样本数 | n_branches=5, n_runs=3 | n_samples=3 |
| 随机种子 | seed=42 | seed=42 |
| 设备 | CUDA | CUDA |

### 3.2 Top-N Accuracy

```
                    Euler-Beam          Euler
Top-1 Acc:         58.000%             54.000%    (+4.0pp)
Top-2 Acc:         68.000%             66.000%    (+2.0pp)
Top-3 Acc:         76.000%             74.000%    (+2.0pp)
```

Euler-Beam 在所有 Top-N 指标上**一致优于**普通 Euler，Top-1 提升最显著（+4pp）。

### 3.3 MaxFrag Accuracy（最大片段匹配）

```
                    Euler-Beam          Euler
MaxFrag Top-1:     62.000%             60.000%    (+2.0pp)
MaxFrag Top-2:     74.000%             74.000%
MaxFrag Top-3:     82.000%             80.000%    (+2.0pp)
```

### 3.4 生成质量

```
                    Euler-Beam          Euler
Invalid SMILES:    19.1~20.3%          20.3~21.3%  (-1.2pp, 略优)
Unique Rates:      166.667%            166.667%    (持平)
```

Invalid SMILES 率略低于 Euler，说明去重加权和剪枝有助于过滤低质量路径。

### 3.5 关键发现

1. **Top-1 增益最大 (+4pp)**: 分支并行 + 排序剪枝直接提升了最优预测的质量
2. **Top-2/3 也有稳定增益**: 多样性保留策略避免了过早丢弃有价值的路径
3. **MaxFrag 改善**: 即使整体 SMILES 不完全正确，最大片段的匹配度也更高
4. **Invalid SMILES 略低**: 共识机制天然过滤了一些低质量输出

### 3.6 后续配置更新（2026-08-01）

上述实验之后完成了 **K×M 扩展** 与 **概率质量聚合**，同一 50 产物集上的正式配置 **K=3, M=2, changed_state_bonus=0.5, n_runs=3**：

```
Top-1/2/3:    58% / 64% / 66%
Invalid rank: 13.0% / 14.1% / 13.1%
时间:         231.130 s（vs 单路径完整概率基线 479.062 s）
```

相比单路径完整概率基线（30/54/60），Top-1/2/3 提升 28/10/6pp，Top-1 持平本报告 §3.2 的 58%，耗时约加速 2×。同时发现 **M=4 明显回归、K=5 无增益**，下一阶段转向保留互补状态多样性，而非继续加大 M/K。

## 4. 工作原理解释

### 为什么 Euler-Beam 更好？

```
普通 Euler (n_samples=3):             Euler-Beam (n_branches=5, n_runs=3):

产物 × 3 次独立采样                  产物 × 3 次独立 run, 每次 run 内:
  ┌→ 轨迹 1 → 结果 A (可能好/坏)      5 条分支并行推进
  │                                    ├→ 分支 1 → 结果 α
  ├→ 轨迹 2 → 结果 B (可能好/坏)       ├→ 分支 2 → 结果 β (与 α 相同 → 合并权重)
  │                                    ├→ 分支 3 → 结果 γ
  └→ 轨迹 3 → 结果 C (可能好/坏)       ├→ 分支 4 → 结果 δ (死锁 → 淘汰)
                                       └→ 分支 5 → 结果 γ (与 3 相同 → 合并权重)
每次采样完全独立, 互不知情
                                      排序: γ (权重2) > β > α → 输出 γ
```

每条「分支」捕获了从当前状态出发的一种可能未来。五条分支共同覆盖了更多的编辑路径空间。去重加权让"殊途同归"的结果获得更高的排名。

## 6. 结论

Euler-Beam 通过**维护多条并行 Euler 轨迹并引入去重加权机制**，在逆合成预测任务上展现了超越普通 Euler 采样的潜力。在 tiny 测试集上，Top-1 ACC 从 54% 提升至 58%（+4pp），Top-3 ACC 从 74% 提升至 76%（+2pp），且 Invalid SMILES 率略有降低。

该方法的核心创新在于：**将 Beam Search 的剪枝效率与 Euler 采样的随机探索能力相结合**，并通过去重加权利用"殊途同归"的共识信号。后续（2026-08-01）在 K=3、M=2、changed_state_bonus=0.5 配置下保持 Top-1 58%，并较单路径概率基线加速约 2×；完整数据集的验证仍在进行中。
