统计口径说明
------------
1. “序列长度”主字段使用训练集 source（product、模型输入）的空格分词长度；同时给出
   target（reactants）长度，避免把两侧长度混在一起。
2. P95 使用 nearest-rank 定义：排序后第 ceil(0.95*N) 个样本，因此至少 95% 样本
   不超过该值。
3. 编辑距离由 train_aligned_src/tgt 中的 INS/DEL/SUB 对齐列统计。归一化编辑距离
   使用“每条样本的 distance / 该样本 raw target token 数”的平均值；同时给出 pooled
   distance / pooled target-token 数作为交叉核对。
4. Fragment 的“平均每 token 原子数”按对应 Atom-level token 数 / Fragment token 数
   计算，不把 Cl、[C@H] 等多字符原子错误地拆成多个原子。

总编辑操作数为 3,085,643。Fragment 的绝对编辑步数减少，但因为 target 序列也大幅
缩短，按目标长度归一化后比例反而更高；两者不能只看单一指标。
