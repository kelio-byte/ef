# 将 DGM 适配到 Edit Flows：已完成内容、边界与下一步

更新日期：2026-08-10  
适用范围：产物 SMILES → 反应物 SMILES 的逆合成推理

> **当前结论先行：** 我们已经实现了一个可运行、可复现实验的“DGM 式引导”原型：它会在逆合成模型每一步编辑分子序列时，依据一个额外训练的引导网络重新分配下一步编辑的偏好。这个原型在方法结构上借鉴了 DGM，但由于 Edit Flows 的状态是可变长度序列，当前只能算是**动作级近似**，不是论文所说的精确 DGM。现有实验表明奖励信号有一定排序信息，但尚未证明引导后的采样能在独立验证集上稳定提高总体准确率；因此它还不是默认推理方法，也不应作为最终性能结论。

> **评估协议与最新结果（2026-08-11）：** 文中此前提到的 validation-A/B 已降级为历史探索结果。新的方法级评估先使用 1,000 个独立反应的开发集，20 条 SMILES augmentation 始终属于同一个原始反应，不能当作 20 个独立样本。开发集上，终点正向重排和两种逐步 guidance 都出现了部分更深 Top-k 收益，但都降低了 Top-1；共享中间状态 guidance 的 Top-10 为 84.9%（基线 83.5%），而 Top-1 为 56.2%（基线 58.2%）。没有方法通过进入确认集的门槛，因此 1,000 个反应的确认集和 2,000 个反应的最终验证集仍未使用。构造细节、时间、置信区间和全部结果见 `new_docs/dgm_evaluation_v2.md`。

## 0. 阅读这份文档前需要知道的四件事

为了避免直接使用代码里的名称，下面统一用这些日常语言描述系统。

| 名称 | 本文中的含义 |
|---|---|
| 基础逆合成模型 | 已训练好的 Edit Flows 模型。给定产物，它从一个初始序列开始，连续执行插入、替换、删除等编辑，逐步生成候选反应物。 |
| 中间状态 | 逆合成尚未结束时的当前分子序列；它可能还不是合法或完整的反应物。 |
| 候选终点 | 一条完整采样轨迹结束后得到的反应物候选。 |
| 正向反应模型 | 冻结的 Molecular Transformer。它接受“候选反应物”，预测可能生成的产物，用来判断这个候选能否在化学上回到给定产物。 |
| 奖励 | 对一个候选终点的非负分数：若正向反应模型能在前几个预测中重构原产物，排名越靠前分数越高；无法重构则为零。它不读取测试集真实反应物。 |
| 引导网络 | 额外训练的小模型。它读取原始产物、当前中间状态和当前采样时间，估计此时哪些编辑更值得偏向。 |

文中的“Top-k 准确率”表示：清理非法和重复候选后，正确反应物是否出现在排名前 k；“候选覆盖率（Oracle）”表示正确答案是否曾出现于整批候选中，不关心最后排在第几。这两个指标分别回答“排得准不准”和“有没有采到正确答案”。

## 一、DGM 与 Edit Flows 的适配：哪些相同、哪些偏离、哪些尚未完成

### 1. DGM 原本要解决什么问题？

一个已经训练好的生成模型通常能生成合理的结果，但它不一定最偏好我们真正想要的结果。例如在逆合成中，它可能生成语法合法、常见的反应物，却不是最能生成目标产物的那一种。DGM 的基本想法是：

1. 保留原有生成模型作为“基础分布”，不重新从头训练它；
2. 用奖励描述“什么样的最终结果更理想”，从而隐式定义一个更想采样到的目标分布；
3. 训练一个能看懂**中间状态**的引导器，估计从当前状态继续生成后，哪些下一步选择更可能通向高奖励终点；
4. 推理时，在每一个生成时间步，用引导器轻度改变基础模型的下一步选择，而不是只在最后对成品排序。

若能够严格得到“理想分布相对基础分布的密度比”，并且状态空间的坐标定义完全一致，DGM 可以给出严格的离散流引导关系。我们的目标是借用这条思路，让 Edit Flows 在生成反应物的过程中更早地避开低质量方向。

### 2. 已经与 DGM 对齐的部分

下表按“先有的建模需求 → 采用的机制 → 与 DGM 的对应关系”说明，而不是直接罗列代码组件。

| 面临的建模需求 | 我们采用的机制 | 与 DGM 的关系 |
|---|---|---|
| 不希望为了改变推理偏好而破坏已经训练好的逆合成能力 | 冻结基础逆合成模型，只训练一个独立的引导网络 | 与 DGM 的“在预训练离散流上学习 guidance”一致。 |
| 需要定义“更理想的反应物”，但测试时绝不能知道真实答案 | 用独立的正向反应模型检查候选反应物能否回到给定产物；奖励只依赖输入产物和候选本身 | 与 DGM 用奖励隐式定义目标偏好一致，也避免测试标签泄漏。 |
| 终点奖励不能直接告诉中间每一步怎么走 | 引导网络同时读取产物、当前中间序列和时间，输出各类可执行编辑的相对正权重 | 对应 DGM 中随时间、随状态变化的条件引导，而不是一个固定的末端重排器。 |
| 编辑模型的下一步本来已有概率或速率 | 将基础模型给出的编辑偏好与引导网络给出的正权重相乘后重新归一化，再按新分布采样 | 对应 DGM 的“用目标/基础偏好比改变下一步转移”。权重全为常数或关闭引导时，结果退化回原始 Euler 采样。 |
| 不能只挑一组看起来好的结果 | 在两个互不重叠的 200 个反应验证区间上，用固定候选预算比较基础采样与引导采样，并记录 Top-1 至 Top-10、覆盖率、非法率、候选多样性和耗时 | 与 DGM 研究中需要同时检验质量、覆盖和计算成本的原则一致。 |

因此，我们已经具备的是：**冻结基础模型 + 无测试标签的终点偏好 + 从中间状态预测引导 + 每步重新加权采样 + 可复现验证**这一完整闭环。

### 3. 为什么不能把当前实现直接称为“精确 DGM”？

这里的差别不是措辞问题，而是由分子序列的状态表示决定的。

#### 3.1 可变长度序列使“同一个坐标”的定义不稳定

精确 DGM 的推导通常假设每个样本由一组固定坐标组成：第 1 个坐标、第 2 个坐标……在任一时刻都能明确对应。这样才能问“只改变第 j 个坐标后，目标分布相对基础分布变了多少”。

Edit Flows 处理的是会变长的 SMILES 序列。插入一个字符后，后面所有位置都会右移；删除一个字符后又会左移。尤其在连续空位中插入时，多个位置映射回原序列的方式并不唯一。对当前数据的映射审计显示，约 **89.735% 的插入情况**落在这类连续空位中，无法唯一地说清“它对应固定坐标中的哪一个位置”。

为保持现有采样器可用，我们没有强行伪造固定坐标，而是采用更实际的近似：直接为当前可执行的“插入什么、替换成什么、删除哪里”等**动作**赋予引导权重。这解决了“如何在真实采样器中实施引导”的工程问题，但不再等同于论文中针对固定坐标的精确后验转移公式。

**结论：** 当前方法应称为“受 DGM 启发的动作级引导”，而非 exact DGM。

#### 3.2 基础模型的一个编辑并不是一个单一分类选择

为了生成编辑，基础模型会同时决定：某个位置要不要编辑、若编辑属于插入/替换/删除哪一类、以及插入或替换的具体字符是什么。若粗暴地只给某个字符乘权重，就可能意外改变“这个位置总体上应不应该编辑”的节奏，导致轨迹不稳定。

因此当前实现先保留每个位置原有的总体编辑强度，再只在该位置的具体可选编辑之间重新分配偏好。这是为了解决“既要引导内容，又不要任意加快或减慢编辑次数”的状态同步问题。它是合理的工程约束，但不是 DGM 原论文唯一指定的形式；另一种把总编辑强度也在位置之间重新分配的做法已在验证集上比较过，表现更差，未作为默认方案。

#### 3.3 终点奖励无法天然变成“每个动作的真实价值”

正向反应模型只能在一条完整候选生成后回答：“这个完整反应物回到原产物的程度如何？”它不能直接告诉我们，在某个半成品序列中尝试每一种可能编辑后，未来的期望奖励各是多少。

目前的做法是先把中间序列与某个已生成的终点对齐，找出从中间状态走向该终点所需的插入、替换、删除动作，再把该终点的奖励作为这些动作的监督信号。这使引导网络至少能学到“高奖励终点路径上出现过哪些动作”，但它仍是一种**粗粒度信用分配**：同一条路径上的动作共享终点分数，不等于每个动作都经过独立的反事实验证。

若要得到更接近严格 DGM 的动作价值，需要对每个候选动作分别继续采样许多后续轨迹并估计平均回报。由于每个位置有大量可插入或替换的字符，这会造成组合数量爆炸；而采样和化学评分又不可微，直接在线优化会变成高方差、昂贵的强化学习问题。目前没有采用这种方案。

#### 3.4 奖励是“有方向的代理”，不是已知的真实密度比

理论上，DGM 需要的是“理想终点分布相对基础终点分布的偏好比例”。在逆合成任务中，我们并不知道这个精确比例，也不能用测试集真实反应物来构造它。

当前以正向重构排名构造奖励：候选反应物若能被正向模型预测回输入产物，就更受偏好。这一信号确实与化学闭环有关，但它不是正确反应物的完美判据。验证中，正确候选的平均奖励高于错误候选，但仍有约 **50.56% 的错误候选**也会被正向模型误认为可以重构产物。因此，该奖励只能近似目标偏好，不能当作精确密度比或“化学正确性真值”。

### 4. 当前尚未做、或目前不宜直接适配的部分

#### 已明确尚未完成

1. **更可靠、与逆合成准确率更一致的奖励。** 当前奖励验证了方向性，但区分正确与错误候选的能力不够强。尚未训练专门的“产物—候选反应物是否为正确逆合成对”的判别模型。
2. **经过验证的动作价值学习。** 目前只把终点奖励沿对齐路径传播；尚未用受控的后续采样或其他方法验证这种传播是否准确反映单个动作的长期价值。
3. **稳定的引导损失设计。** 已发现“让同一状态下高奖励路径排得更靠前”与“让预测权重的绝对大小和奖励匹配”之间有权衡，尚未找到同时稳定二者的设计。
4. **普通 Euler 上的稳定收益。** 当前两个独立验证区间的结果方向不一致，未达到预先设定的通过标准；因此没有扩大到完整测试集。
5. **与多分支 Euler-Beam 的结合。** 当前引导只接入普通 Euler。若基础引导本身还不稳定，过早叠加分支、合并和重排序会使原因难以区分，因此尚未接入。
6. **减少采样步数。** 当前仍执行 100 步；引导网络还会在每一步额外前向一次。尚未证明 50 步或更少步数能够保持质量，更没有实现一步生成。

#### 当前不应直接照搬的部分

1. **固定坐标下的精确 DGM 公式。** 在可变长度、含插入删除的现有表示中，坐标映射大量不唯一。除非重新设计带持久身份标记的序列表示和可验证的映射，否则直接套用会造成“公式中的坐标”和“采样器实际编辑位置”不一致。
2. **测试时使用真实反应物评分。** 这会让奖励直接看到答案，得到的指标没有泛化意义；它只能用于离线分析，不能用于训练验证或实际推理。
3. **逐个枚举所有可能编辑并即时做完整正向评分。** 每一步的候选编辑数随序列长度和词表增长，给每一个编辑都做多次后续采样和正向反应预测，在计算上不可承受，也会大幅降低推理效率。
4. **把“引导”理解为天然加速。** 当前引导是在 100 步中每步多运行一个网络，实际反而增加时间。只有先证明质量稳定，再做减少步数或蒸馏，才有讨论加速的基础。

## 二、目前进度、已经取得的成果与实验结论

### 1. 已完成的工程与正确性工作

1. **正向反应评分链路已可用。** Molecular Transformer 已能够在当前环境中加载，并接受候选反应物、输出产物预测排名；它的词表和 Edit Flows 词表分离处理，避免混用。
2. **奖励数据可离线构建。** 使用冻结的基础逆合成模型为训练产物生成多个候选终点，再用正向反应模型评分。引导网络训练时读取这些离线记录，不会在每个训练批次重新采样或调用正向模型，因而训练成本可控。
3. **引导网络和逐步采样接口已实现。** 它能够为插入、替换、删除等可执行动作产生正权重，并在普通 Euler 的每一步影响下一次编辑选择。关闭引导时，输出与原始普通 Euler 一致；这些恒等性与 CPU/CUDA 冒烟测试已通过。
4. **公平比较多条未来路径的数据构造已修正。** 早期记录中，同一个产物的不同终点往往来自不同中间状态或不同时间，因此无法公平地问“在相同处境下，哪条未来更好”。现在已改为：先构造完全相同的中间状态与时间，再从该处出发生成多条不同后续。这样才可以训练或评估相对偏好。
5. **评估口径已固定。** 质量方面记录 Top-1 至 Top-10、候选覆盖率、非法率和去重后的候选数；效率方面记录采样耗时、奖励计算耗时、显存等。完整测试集只应在验证门槛通过后使用。

### 2. 已得到的可汇报实验结果

以下所有准确率都是受控验证实验，不是完整测试集最终成绩。两块验证集各含 200 个互不重叠的反应；普通 Euler 均使用 100 个时间步，每个反应以相同候选预算采样。

#### 2.1 正向反应评分本身有可用信号，但不是完美裁判

在 200 个已知反应上，将真实反应物输入正向反应模型后，原产物出现在其前 1、前 3、前 5 个预测中的比例分别为 **71% / 77% / 79%**，平均倒数排名为 **0.7414**。

这说明该模型可以作为弱监督来源：它通常能识别“反应物能否生成该产物”。但 79% 的前五命中也同时说明它不是完美反应规则库，不能把它的分数直接当成真实正确性。

#### 2.2 仅在终点重排时，奖励带来小而明确的正向信号

在验证区间 B（200 个反应）中，先由基础普通 Euler 生成相同候选池，再只根据正向反应得分对终点候选重新排序：

| 方法 | Top-1 | Top-3 | Top-5 | Top-10 | 候选覆盖率 |
|---|---:|---:|---:|---:|---:|
| 基础普通 Euler | 58.5% | 77.5% | 85.5% | 88.5% | 91.0% |
| 用正向评分重排终点 | **59.0%** | **78.5%** | 85.0% | **89.5%** | 91.0% |

这组结果说明：当前奖励至少包含一点有用的排序方向。但它只是在生成结束后排序，**不能证明逐步引导已经有效**。

同时，我们把代表同一化学结构、但写法不同的 SMILES 先规范化并缓存评分结果。该批次中，8,131 个原始字符串归并为 2,332 个合法且唯一的结构，正向评分时间从约 355.8 秒降到 **117.6 秒**，即约 **3.03 倍**提速。这是避免重复计算带来的工程优化，不是正向反应模型本身突然变快。

#### 2.3 已训练引导网络，但采样收益不稳定

使用较大离线数据训练的引导网络，在两个验证区间上以相同的、保守的引导强度测试，结果如下：

| 验证区间 / 方法 | Top-1 | Top-2 | Top-3 | Top-5 | Top-10 | 候选覆盖率 | 采样耗时 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A：基础普通 Euler | 51.0% | 66.5% | 72.0% | 77.0% | 83.5% | 86.5% | 253.0 s |
| A：加入逐步引导 | **53.0%** | 66.5% | 71.5% | **78.5%** | 83.5% | 85.5% | 371.0 s |
| B：基础普通 Euler | **58.5%** | 73.0% | 77.5% | 85.5% | 88.5% | 91.0% | 264.4 s |
| B：加入逐步引导 | 56.5% | **75.0%** | **80.0%** | **86.0%** | 88.5% | **91.5%** | 388.0 s |

解释时应同时说清两面：

- A 上 Top-1 提高了 2 个百分点，但候选覆盖率下降了 1 个百分点；
- B 上 Top-1 下降了 2 个百分点，但 Top-2、Top-3、Top-5 与覆盖率提高；
- 两块数据的变化方向不一致，且采样时间约增加 **47%**。

因此，这不是“DGM 已经提升了 Edit Flows”的证据。它只能说明：引导信号确实足以改变生成分布，而且局部指标有潜力；但是当前奖励和训练目标还不足以稳定改善整体质量。

#### 2.4 对训练目标的进一步诊断：发现了排序与校准的冲突

为了让引导网络在同一中间状态下更偏好高奖励未来，我们在小规模、共享同一中间状态的数据上做了受控比较。这里有两个不同要求：

- **相对排序正确：** 高奖励路径的引导分数应高于低奖励路径；
- **绝对大小可靠：** 引导分数不能只会比较大小，还应与奖励强弱大体对应，否则推理时容易放大噪声。

仅加强相对排序时，成对排序正确率从 **55.15%** 升至 **59.66%**，但“分数与奖励强弱的一致程度”反而明显下降。加入一个小的校准约束后，一致程度有所恢复，却仍低于不加排序项的对照，并且训练时间从约 118 秒增至约 229 秒。

这说明目前的瓶颈不是“网络完全学不会”，而是：**现有奖励太粗、终点到动作的信用分配太弱，使得排序目标和数值校准目标彼此拉扯。** 该小型诊断没有通过进入大规模训练和完整采样评估的门槛。

### 3. 哪些结果可以积极汇报，哪些不能？

可以积极但谨慎地汇报：

1. 已建成不使用测试答案的完整闭环，并通过“关闭引导即回到基础采样”的正确性验证；
2. 正向反应评分对候选排序有可测的弱判别力，终点重排在一个独立验证区间带来 Top-1 +0.5、Top-3 +1.0、Top-10 +1.0 个百分点；
3. 对重复 SMILES 的规范化与缓存让评分约快 3.03 倍；
4. 公平的“相同中间状态、多条未来”数据问题已被发现并修正，这是后续训练可信度的重要前提；
5. 引导网络能够改变逐步生成的偏好，并在局部指标上出现提升，说明方法不是空的接口。

不能这样汇报：

1. 不能说已经实现精确 DGM；
2. 不能说 learned guidance 已经稳定提高逆合成 Top-1 或总体性能；
3. 不能把仅终点重排的收益表述为“逐步 DGM 引导收益”；
4. 不能说引导已使采样更快或减少到一步；当前反而约慢 47%；
5. 不能将早期“不同中间状态之间的路径排序”指标当作严格的偏好学习证据；该比较条件已经被后续审计判定为不公平。

## 三、下一步规划：按证据逐层推进，而不是扩大试验规模

后续目标不是继续在小验证集上反复调参数，而是先补足导致不稳定的建模环节。每一阶段都应完成代码、单元/冒烟测试、固定验证实验、文档记录和 Git 提交后再进入下一阶段。

### 阶段 1：先验证并改进“什么是好候选”的判据

**问题。** 当前正向重构分数会给不少错误候选较高分，因此它无法可靠地代表逆合成正确性。

**要做什么。** 在训练数据范围内构造正例（真实产物—反应物对）和由基础模型生成的困难负例，训练或校准一个独立的正确性判别器。它的输入是产物和候选反应物，输出候选成为正确逆合成答案的可信程度。正向重构分数可作为一个特征或辅助信号，但不再是唯一依据。

**如何验证通过。** 在与训练完全隔离的验证反应上比较新旧奖励对“正确/错误候选”的区分能力、候选末端重排的 Top-1 至 Top-10、覆盖率、非法率和耗时。只有在两个独立验证区间上不牺牲 Top-1 且至少改善一个覆盖类指标时，才将其作为引导监督来源。测试集真实反应物始终不得参与评分。

### 阶段 2：让训练数据真正回答“同一处境下该走哪一步”

**问题。** 若两条未来来自不同中间状态，就不能据其好坏教会模型在同一时刻如何选择。

**要做什么。** 保留已修正的共同中间状态构造：对同一个产物，在相同时间、相同部分序列处启动多条独立后续，再由改进后的奖励给这些终点评分。仅在这些可比路径之间学习偏好。进一步用少量受控后续采样检查“将终点奖励传播到路径动作”的近似误差，而不是默认它一定正确。

**如何验证通过。** 高奖励路径应在同一中间状态下被更可靠地排在前面，同时预测分数的绝对大小仍应和奖励强弱保持一致；二者必须同时优于对照，不能只提升其中一个。

### 阶段 3：确定一个兼顾排序和稳定性的训练目标

**问题。** 只追求“高奖励比低奖励分数大”会使权重数值失真；只拟合终点奖励又可能缺少相对选择能力。

**要做什么。** 在阶段 2 的公平数据上，预先确定一个保守的联合目标：既保留动作级监督，使权重大小可控；又只在同一中间状态内加入有限的相对偏好约束。实验不进行无边界网格搜索，而是先定义少量候选设计、验证门槛和选择规则。

**如何验证通过。** 选出的模型必须同时满足：训练/验证曲线稳定、相对排序和数值校准均不低于对照，并且增加的训练成本可接受。否则回到阶段 1 检查奖励，而不是盲目增加训练步数。

### 阶段 4：在普通 Euler 上做严格、冻结参数的采样检验

**问题。** 训练诊断改善不等于最终逆合成质量改善。

**要做什么。** 在一个验证区间选择好模型和引导强度后，固定所有设置，在另一个不重叠验证区间复现。基础采样与引导采样必须使用相同的时间步数（先固定 100 步）、随机种子策略和候选预算。

**如何验证通过。** 两个验证区间都要求 Top-1 不下降，并且各自至少有一个指标（Top-3、Top-10 或候选覆盖率）提升；同时完整报告非法率、候选去重后的多样性、耗时和显存。未通过则不进入完整测试集，也不接入分支采样。

### 阶段 5：只有普通 Euler 通过后，才接入多分支推理

**问题。** 多分支采样本身就会引入候选扩张、合并、排序和计算预算问题；若基础引导不稳定，无法判断收益来自哪里。

**要做什么。** 在普通 Euler 通过后，将相同的逐步引导作用于多分支搜索，并严格固定总模型前向次数和总候选数，和不带引导的多分支方法进行同预算比较。

**如何验证通过。** 在独立验证集上同时维持或提高 Top-1，并改善 Top-3、Top-10 或候选覆盖率；不得通过无限增加分支数换取表面提升。还需记录分支坍缩、重复候选比例、重排开销和总耗时。

### 阶段 6：作为长期研究支线，处理精确 DGM 与加速问题

**问题。** 目前的可变长度表示无法提供精确 DGM 所需的稳定坐标，而且逐步引导尚未带来加速。

**要做什么。** 若前面阶段已经证明奖励和引导有效，再研究带持久位置身份的固定坐标表示，验证插入删除与该表示之间的一一映射；同时比较 50、100、200 步，在质量不下降时才尝试减少时间步数或蒸馏。

**如何验证通过。** 只有映射在理论和实现上都可验证、并且较少时间步在独立验证上稳定保持质量时，才可将结果表述为更接近精确 DGM 或推理加速。

## 四、当前项目状态的一句话版本

我们已经把 DGM 的核心思想——“由最终质量信号训练一个随中间状态变化的引导器，并在每一步改变基础生成模型的选择”——安全地接入了 Edit Flows；目前最大的收获是建立了可信的实验与诊断框架，并确认正向化学闭环奖励有弱但可测的价值。当前最大瓶颈是奖励与真实逆合成正确性并不完全一致，加上可变长度编辑使终点奖励难以精确归因到单个动作。下一步应优先提高奖励质量和动作价值监督的可信度，待普通 Euler 在两个独立验证集上取得稳定收益后，再扩展到多分支搜索、完整测试集和更严格的 DGM 表述。
